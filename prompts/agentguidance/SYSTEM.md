## System

- `~/source` — Clones of other people's projects, named
  `<upstream-owner>--<repo>`. The original remote is `upstream`; our optional
  GitHub fork is `fork`.
- `~/code` — the operator's own projects, source and otherwise. A bare
  project name in a request usually means a directory here, unless it is a
  Workshop.
- `~/workshops` — first-party fork maintenance repositories (`codexnk`,
  `fxnk`, `nekomancer`, `tuilet`, `zmax`). Their bound fork checkouts remain
  where each Workshop declares them, either under `~/source` or inside the
  Workshop; moving a Workshop does not move an external Clone.
- `/Volumes/Scratch/coldstorage/mike` — cold-storage backups of the previous
  computer and profile, on an external volume that is not always mounted.
