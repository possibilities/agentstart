# 0008: Record routing decisions in native history

Accepted for implementation September 13, 2026. The human requested model,
effort and task choices with decision context and outcome evidence for later
routing evaluation. Extends [0006](0006-own-manager-worker-roles.md).

Manager and worker roles replace an unobservable internal choice with a concise
structured receipt at substantive direct/delegation/reuse/escalation decisions.
They call AgentChats' validated `routing-receipt` formatter through its supported
MCP or CLI. The formatter returns a tool result and writes no private sidecar,
index row or archive. Native history owns retention. No requirement depends on
recovering hidden reasoning or capturing private source bodies.

The deciding agent supplies a unique decision ID, short task/reason, requested
settings and evidence references. The parent records acceptance of a delegated
assignment after checking evidence. Native terminal completion and human
presentation stay separate. Failed, pending and unobservable cases remain
useful evidence; a strong model's route is not a verified training label.

Tool discovery and the AgentChats guide own schema detail. An unavailable tool
creates a visible evidence gap, not a reason to stall authorized work. No role
or model switch, native child-role injection, live restart, new retention policy,
training export or optimization run follows from this instruction change.

Deliver AgentChats' routing commands before publishing the role guidance through
the supported sync path. Existing loaded sessions and snapshots retain their
own contents. Prompt rendering proves delivery of instructions, not behavioral
compliance or capture completeness.
