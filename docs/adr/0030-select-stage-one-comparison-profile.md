# 0030: Select the Stage 1 AgentFX comparison profile

Accepted September 18, 2026.

## Decision

Manager guidance selects AgentFX Comparison profile
`agentfx-stage-1-shadow` revision 1 when approved comparison Work applies. The
manager freezes equivalent starting inputs and resolves the profile into an
immutable digest-bound manifest before dispatch. One fresh native Codex control
and one isolated AgentFX/Grok 4.6 medium shadow receive separate Assignments,
routing receipts, worktrees, artifact roots, and binding-evidence references.
Each lane has one repetition, one prompt, and zero child delegation.

Stage 1 outputs are comparison evidence only. Managers do not steer, resume,
chain, automatically integrate, retry an uncertain attempt, or silently replace
a refused/unknown lane. Stages 2 and 3 remain disabled recipes until a later
explicit human promotion. Ordinary delivery obligations continue under their
existing Work, authority, review, and delivery contracts.

This supersedes the automatic comparison-profile exception in
[ADR 0028](0028-expose-agentfx-to-managers.md). The former named state is
historical context, not selectable manager behavior.

## Ownership

AgentStart distributes manager selection and recording guidance. AgentFX owns
only its data contract and Fx Execution lifecycle. Native dispatch remains the
harness's operation, AgentUsage retains current eligibility and provider
admission, and AgentHUD retains Work, Assignment, Result, acceptance, and
presentation. This decision adds no scheduler, HUD action, model catalog,
fallback path, or execution authority.
