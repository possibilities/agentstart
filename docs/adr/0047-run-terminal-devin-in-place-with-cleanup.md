# 0047: Run terminal Devin in place with guarded snapshot cleanup

Accepted September 25, 2026. Supersedes [ADR 0045](0045-delegate-devin-role-to-worktree.md)'s terminal worktree and resume-location decision; preserves its Role snapshot, native CLI, utility/ACP bypass and explicit `/prime` behavior.

Devin should see the caller's source and uncommitted edits rather than a fresh branch. The public terminal wrapper now creates its disposable `.devin` Role snapshot at the Git root and launches the native binary from the original cwd. Existing exact-marker worktrees still admit native resume without a second snapshot. Since temporary in-place content can survive a killed wrapper, an AgentStart-owned periodic LaunchAgent reconciles per-root invocation records under the local state directory. A record binds an invocation ID and cwd to wrapper and child PIDs **and their kernel start times in microseconds**; PID existence alone is insufficient after reuse. Cleanup waits for both identities to end, verifies the exact ownership marker, and removes only unchanged snapshot files. Foreign `.devin` contents and concurrent invocations are refused. This briefly exposes `.devin` as untracked project content; no Git exclude, branch, or worktree is changed on the user's behalf.
