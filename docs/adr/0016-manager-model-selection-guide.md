# 0016: Give the manager an explicit model-selection guide

Accepted September 14, 2026. Supersedes the model-policy separation in
[ADR 0009](0009-conversational-front-selective-managers.md) only for this
operator's requested manager guide. Its selective delegation and checked
acceptance contract remains in force. The earlier Sol/low front was provisional;
this change does not activate it.

An audit found economical generic prose but no explicit Sol worker preference,
while most sampled native launches selected Astra. The human authorized a
manager-only guide: the AgentVoice root currently uses Astra/low, ordinary new
children default to Sol/medium, and high/xhigh Sol remains a normal choice for
harder implementation. Astra is reserved for exceptional architecture,
design/product or complex workflows unless the human explicitly chooses it.
Receipts explain the model and effort, not just the value of delegation.

Keep the small model/effort table and briefing advice in the manager APPEND so
they reach the actual delegator through existing role rendering. The live native
catalog overrides the dated table. Other managers may have different settings;
the Voice deployment statement is not a runtime identity assertion. Preserve
native inheritance/reuse restrictions and configured service tier. Do not change
the worker prompt, MCP inventories, role loader or runtime model settings.

[Source provenance](../manager-model-routing.md) separates retrieved Brain
prompting material, fresh public model cards, current native options and
AgentUsage's account-scoped usage observations. Public API capabilities do not
establish subscription/native availability, and usage lanes are not a model
catalog. Spark has its own finite quota, but the current role excludes Spark
workers and the native spawn catalog does not advertise it. Enabling it requires
a separate policy/capability disposition; this change does not bypass either.

Use existing document, role render and full repository validation, inspect the
manager/worker scope, then converge the installed resources through the supported
nonrestarting sync. Verify future loaded behavior during ordinary authorized
work. No benchmark, live model switch, snapshot migration or restart is part of
this delivery.
