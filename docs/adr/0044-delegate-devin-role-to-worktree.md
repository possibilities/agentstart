# 0044: Deliver Devin's default Role in a per-session worktree

Accepted September 24, 2026. Extends [ADR 0040](0040-collapse-explicit-roles-to-default.md)'s one Role and [ADR 0041](0041-bind-harness-shims-to-owned-forks.md)'s separation of vendor commands from AgentStart wrappers. Replaces the machine's previously installed sticky `default` Devin plugin for ordinary AgentStart terminal launches; AgentRoles retains its explicit plugin-install feature for other users.

Devin CLI has no per-invocation Role root or prompt flag. AgentStart therefore wraps only new terminal sessions at its public `~/.local/bin/devin` path, retaining the official versioned binary and native credentials. It creates a fresh Git worktree from the source checkout's committed HEAD without copying uncommitted edits. Within that worktree a self-ignored `.devin/` holds copied default-Role skills, a local MCP config from the same role, config-import restrictions, and a user-triggered `/prime` skill containing `APPEND_SYSTEM_PROMPT.md`. `/prime` is not injected automatically. Session results and branches remain in the worktree for review; resume requires starting from that exact owned worktree. Utility commands and `devin acp` bypass the wrapper's worktree operation, so AgentStack owns its ACP session worktrees independently. The Role renderer remains the one resource source; edits affect later invocations.

The existing `install-harness-shims` contract publishes the direct public wrapper atomically only when it finds the exact official Devin launcher link or its own marker. A foreign command is retained and refused. The full AgentStart installer obtains the official CLI only if its native binary is absent, never re-runs the vendor installer over a working wrapper, and does not restart a running session. Installation does not remove plugins. A no-plugin disposable-profile probe and a test of the installed public wrapper must establish that Devin sees `/prime`, the Role skills and Role MCPs before the separate, exact `retire-devin-default-plugin.ts` cutover removes the AgentRoles-sourced local `default` plugin. That helper checks provenance and live process state. Ordinary unattended `sync-skills` never removes plugins.
