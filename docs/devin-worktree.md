# Devin terminal worktrees

AgentStart's public `~/.local/bin/devin` is an ownership-checked wrapper around Devin's separately installed native CLI. A new terminal session started from a Git repository root or subdirectory creates `~/worktrees/<repo>/devin-<uuid>/<repo>` on an `agentstart-devin-<uuid>` branch at the source checkout's committed `HEAD`. It prints the path and branch. Source edits not committed at that HEAD are not copied, and neither the source checkout nor its Git exclude configuration is changed. A source branch with an existing tracked `.devin` is refused rather than overwritten.

The worktree's self-ignored `.devin/` contains a copy of the current AgentStart `default` Role skills, its MCP definitions in `mcp_config.local.json`, and a user-triggered `/prime` skill containing `APPEND_SYSTEM_PROMPT.md`. Invoke `/prime` manually when those working instructions are relevant; they are not an always-on rule. The project `AGENTS.md` remains available, while imports from other tool configurations are disabled for this invocation. Later Role changes affect a new worktree, not a running session.

`devin acp`, `devin auth`, `devin models`, `devin mcp`, `devin plugins`, help/version and other native utilities pass through without creating a worktree. AgentStack supplies its own ACP Worker's Git worktree and calls the native `devin acp` path. `devin -c` and `devin -r <id>` must be run from the original AgentStart-owned worktree so a resume cannot silently attach to another source directory. For an explicit native invocation without the wrapper, set `AGENTSTART_SHIM_BYPASS=1` for that command.

AgentStart retains worktrees and branches after a terminal session exits. Review the diff and any commits before removing an owned worktree. The wrapper never cleans, resets, rebases or commits a repository on your behalf.

The full installer fetches the official Devin CLI only when its native versioned binary is absent and then uses `install-harness-shims` to publish the wrapper at the public path without overwriting a foreign command. Installation leaves plugin state alone. After testing the installed wrapper, run `bun scripts/retire-devin-default-plugin.ts "$HOME/.local/share/devin/cli/_versions/current/bin/devin" "$HOME"` from AgentStart's checkout. That one-time helper removes only the exact local AgentRoles-sourced `default` plugin when no Devin process is running; a login failure or active session defers the cutover. Unattended `sync-skills` never uninstalls a plugin.
