# Devin terminal invocations

AgentStart's public `~/.local/bin/devin` wraps the separately installed native CLI. Terminal sessions start **in the caller's current directory**; the wrapper discovers the Git root to place a temporary `.devin/` Role snapshot there. Existing tracked or untracked `.devin` content is never overwritten. The snapshot includes the current default Role skills, local MCP definitions, config-import restrictions, and a manual `/prime` skill. The native login, sessions, and arguments are unchanged. The temporary directory is visible to Git until cleanup; the wrapper does not edit Git configuration or ignore files. Devin can work on uncommitted changes in the source checkout.

One invocation at a time may use a given Git root. Before creating `.devin`, the wrapper claims `~/.local/state/agentstart/devin-invocations/<sha256-of-real-Git-root>.json` with the real cwd, an invocation ID, its PID and microsecond-resolution kernel start time. The path is fixed even when a terminal overrides `XDG_STATE_HOME`, so the cleanup job sees it. The wrapper adds the child process identity and hashes of the snapshot files before returning. A second launch from that root fails closed while the claim remains; wait at most one cleanup interval or run `agentstart devin cleanup` after the previous session exits. A resume from the same source directory creates a fresh snapshot; it does not require an old worktree.

The AgentStart-owned periodic `io.arthack.agentstart.clean-devin` LaunchAgent runs at login and every 30 seconds. It checks both wrapper and native child identities, so a recycled PID cannot hold or prematurely clean a session. It only removes matching, unchanged files beneath a directory carrying the exact invocation ownership marker; new or edited files are left in place. A wrapper crash before completion of the snapshot removes its entirely marked partial staging directory. Unknown, malformed, and foreign state is not cleaned by guessing. The daemon never modifies a Git branch or a native Devin session.

`devin acp`, native utilities, help/version, and explicit `AGENTSTART_SHIM_BYPASS=1` pass through without a snapshot. AgentStack's ACP workers remain outside this terminal wrapper. `/prime` is invoked manually, never injected. The installer does not change the sticky `default` plugin; the separate retirement helper still requires a disposable-profile native proof of the installed wrapper before use.

Existing AgentStart-owned Devin worktrees from the former wrapper are preserved. A resume (`-c`/`-r`) inside one of those exact marked worktrees passes through to native Devin without creating a new snapshot; new sessions in ordinary project checkouts never create worktrees.
